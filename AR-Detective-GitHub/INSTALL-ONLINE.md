# AR Detective : คดีลับจับใจความ — ชุดส่งมอบระบบออนไลน์

ตัวเกมเป็น HTML แบบคลิกหรือแตะคำตอบ มี 8 แฟ้มคดี แฟ้มละ 6 ด่าน รวม 240 ข้อ ไม่มีลายน้ำเพจ

ฉบับนี้แก้เสียงเอฟเฟกต์ซ้อนแล้ว ใช้เพลงพื้นหลังหนึ่งชุดและระบบเอฟเฟกต์หนึ่งระบบ เพลงจะหยุดเมื่อซ่อนแท็บเกม และมีปุ่มเปิด–ปิดเพลงกับเอฟเฟกต์แยกกัน

คำถามทั้ง 240 ข้อใช้ข้อความไม่ซ้ำกันข้ามด่าน และใช้บทอ่านคนละเรื่องในแต่ละด่าน (48 เรื่อง) ระบบปฏิเสธคำถามซ้ำแม้เปลี่ยนบทอ่าน เว้นวรรค หรือเครื่องหมายวรรคตอน

## ตัวละคร คู่หู และรางวัล

- เด็กเลือกตัวละครจากภาพได้ที่หน้าเริ่มภารกิจ เกมจำตัวที่เลือกไว้ในเบราว์เซอร์ของเด็ก
- ตัวเริ่มต้น: มีนา อคิน ใบบัว และต้นกล้า มีทั้งชายและหญิง
- ตัวละครลับ: ลูน่าปลดล็อกเมื่อผ่าน 12 ด่าน และน็อกซ์เมื่อผ่าน 24 ด่าน โดยนับด่านที่ไม่ซ้ำ
- คู่หูโฮปเติมหัวใจได้ 1 ดวง (สูงสุด 3) โมจิเพิ่มเวลา 5 วินาที ฮูกตัดคำตอบผิด 1 ข้อ และรูบี้ตัดคำตอบผิด 2 ข้อ
- โมจิปลดล็อกที่ 6 ด่าน ฮูกที่ 12 ด่าน และรูบี้ที่ 24 ด่าน แต่ละด่านใช้พลังได้ครั้งเดียว การเปลี่ยนคู่หูหรือเล่นซ้ำไม่เพิ่มจำนวนครั้ง
- ผ่านทุก 3 ด่านที่ไม่ซ้ำรับหีบสมบัติ 1 หีบ หีบทองแดงได้ 60 เหรียญ ตั้งแต่ด่านสะสมที่ 12 ได้หีบเงิน 100 เหรียญ และตั้งแต่ด่านสะสมที่ 24 ได้หีบทอง 160 เหรียญ
- ภาพทั้ง 13 ไฟล์เป็น PNG พื้นหลังโปร่งใส อยู่ใน client/assets และ public/assets

ครูเข้าสู่ระบบ แก้บทอ่าน คำถาม ตัวเลือก และเฉลย แล้วกด **เผยแพร่ข้อสอบให้นักเรียน** ข้อสอบจะบันทึกบน Netlify ส่วนกลาง นักเรียนเปิดหรือรีเฟรชลิงก์เดิมเพื่อรับชุดล่าสุดได้ โดยไม่ต้องสมัครบัญชีและไม่ต้องนำเข้าไฟล์เอง

## สิ่งที่ต้องส่งให้คุณครู

ส่ง ZIP นี้ทั้งชุดและให้แตกไฟล์ก่อนติดตั้ง ตัวเกมอยู่ที่ `public/index.html` แต่ระบบออนไลน์ต้องใช้ไฟล์อื่นในชุดด้วย การลากเฉพาะ HTML หรือโฟลเดอร์ public ลง Netlify Drop จะไม่ติดตั้งระบบข้อสอบและบัญชีครู

ชุดนี้ยังไม่ได้ติดตั้งในบัญชี Netlify ของผู้รับงาน และยังไม่มีบัญชีครูที่ตั้งให้ล่วงหน้า

## ติดตั้งครั้งแรกบน Netlify ของผู้รับงาน

หากคุณครูไม่สะดวกติดตั้ง ให้ผู้พัฒนาหรือผู้ดูแลเว็บทำขั้นตอนนี้ในบัญชี Netlify ของคุณครูครั้งเดียว

1. ติดตั้ง Node.js รุ่น 22.12 ขึ้นไปจาก [เว็บไซต์ Node.js](https://nodejs.org/) แล้วแตก ZIP นี้ลงในโฟลเดอร์บนเครื่อง
2. บน Windows เปิด `INSTALL-NETLIFY.cmd` ไฟล์จะติดตั้งส่วนประกอบ ตรวจระบบ และเปิดให้เข้าสู่บัญชี Netlify
3. เมื่อเครื่องมือถามว่าจะใช้เว็บไซต์ใด ให้เลือกเว็บไซต์ของผู้รับงานที่ต้องการติดตั้ง หรือสร้างเว็บไซต์ใหม่ตามตัวเลือกบนหน้าจอ การเลือกเว็บไซต์เดิมจะอัปโหลดเกมนี้แทนไฟล์เว็บเดิม
4. รอข้อความยืนยันการเผยแพร่และเก็บลิงก์เว็บไซต์ที่ได้ไว้
5. ในหน้า Netlify ของเว็บไซต์นั้น เปิด **Project configuration → Identity** แล้วเปิดใช้ Identity
6. ตั้ง Registration เป็น **Invite only** เพื่อให้ใช้งานบัญชีจากคำเชิญ
7. เชิญอีเมลคุณครูผ่านหน้า Identity แล้วกำหนดบทบาท **teacher** ให้ผู้ใช้รายนั้นผ่านช่อง Roles/User information ของ Netlify
8. คุณครูเปิดอีเมลคำเชิญ ตั้งรหัสผ่านผ่านหน้าเกม แล้วเข้าสู่ระบบ หากเพิ่งเพิ่มบทบาท ให้ลงชื่อออกและเข้าสู่ระบบใหม่
9. เปิดหน้าเกมแล้วกด **ตั้งค่าข้อสอบ** หรือเปิดลิงก์เว็บตามด้วย `/admin`

ไม่มีรหัสผ่านเริ่มต้นร่วมกันในชุดไฟล์นี้ คุณครูตั้งรหัสผ่านเองผ่านคำเชิญ หากหน้า Identity หรือเมนูต่างจากคำอธิบาย ให้ผู้ดูแลตรวจ [คู่มือ Netlify Identity](https://docs.netlify.com/security/secure-access-to-sites/identity/registration-login/)

ทางเลือกสำหรับผู้พัฒนา: อัปโหลดโครงการนี้เข้า Git repository แล้วเชื่อม Netlify โดยใช้ Build command `npm run build`, Publish directory `public`, Functions directory `netlify/functions` จากนั้นทำขั้นตอน Identity และบัญชีครูเช่นเดียวกัน

## แก้ข้อสอบหลังติดตั้ง

1. ครูเปิดเว็บแล้วกด **ตั้งค่าข้อสอบ** และเข้าสู่ระบบด้วยอีเมลที่ได้รับบทบาท teacher
2. เลือกแฟ้มคดี ด่าน และข้อที่ต้องการ แล้วแก้บทอ่าน คำถาม ตัวเลือก A–D และเฉลย
3. กด **เผยแพร่ข้อสอบให้นักเรียน** รอข้อความยืนยันการเผยแพร่สำเร็จ
4. ให้นักเรียนเปิดหรือรีเฟรชลิงก์เดิม ข้อสอบชุดล่าสุดจะถูกโหลดจากส่วนกลาง

นักเรียนที่เล่นอยู่จะใช้ชุดที่โหลดไว้จนกว่าจะรีเฟรช การเผยแพร่แต่ละครั้งสร้างรุ่นข้อสอบใหม่และแยกความคืบหน้าตามรุ่น เพื่อไม่ให้เกมที่เล่นค้างหรือคะแนนจากข้อสอบเก่าปนกับชุดใหม่

เมื่อครูสองหน้าจอแก้พร้อมกัน ระบบจะไม่เขียนทับชุดที่อีกหน้าจอเพิ่งเผยแพร่ ให้กดสำรองข้อสอบ JSON เก็บการแก้ไขไว้ รีเฟรชเพื่อรับชุดล่าสุด แล้วตรวจรวมการแก้ไขก่อนเผยแพร่อีกครั้ง

## ตรวจรับงานหลังติดตั้ง

1. เปิดเว็บโดยยังไม่เข้าสู่ระบบ ต้องเล่นด้วยการคลิกได้ และไม่สามารถเผยแพร่ข้อสอบได้
2. เข้าด้วยบัญชีครู แก้คำถามหนึ่งข้อ แล้วกดเผยแพร่
3. เปิดลิงก์บนโทรศัพท์หรืออีกเบราว์เซอร์ที่ไม่ได้เข้าสู่ระบบครู ต้องเห็นข้อที่แก้เมื่อถึงด่านนั้น
4. ทดสอบนำเข้าและสำรองข้อสอบ JSON หากต้องการใช้คลังของตนเอง
5. ทดลองออกจากระบบครู แล้วตรวจว่าเปิดแก้ข้อสอบต้องเข้าสู่ระบบอีกครั้ง

## ข้อควรทราบสำหรับการส่งมอบ

- ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดข้อสอบกลาง ถ้าเชื่อมต่อไม่ได้ เกมจะแจ้งให้ลองใหม่ ไม่ใช้ข้อสอบเก่ามาแทนโดยเงียบ ๆ
- ข้อสอบใช้ Netlify Blobs แบบเก็บต่อเนื่องข้ามการอัปโหลดไฟล์เว็บ การอัปโหลดเกมใหม่ไม่เขียนทับข้อสอบที่ครูเผยแพร่ไว้
- ชื่อและคะแนนของนักเรียนยังอยู่ในเบราว์เซอร์ของนักเรียนเอง ชุดนี้ไม่ได้เพิ่มระบบรวบรวมคะแนนทุกคนเข้าบัญชีครู
- บทอ่านและตัวเลือกแสดงเป็นข้อความ ไม่รับการใส่สคริปต์ลงในข้อสอบ
- ฟอนต์บนเว็บอาจโหลดจาก Google Fonts และมีฟอนต์สำรองเมื่อโหลดไม่ได้
- ค่าใช้งานและข้อจำกัดบริการเป็นไปตามบัญชี Netlify ของผู้รับงาน

## ผลตรวจในชุดที่ส่งมอบ

ผ่านการทดสอบระบบส่วนกลาง 12 รายการ ได้แก่ อ่านข้อสอบโดยไม่เข้าสู่ระบบ ตรวจสิทธิ์ครู ปฏิเสธการเผยแพร่โดยบัญชีทั่วไปและข้ามเว็บ บันทึกแล้วอ่านได้จากผู้เล่นที่ไม่เข้าสู่ระบบ ตรวจคำถามซ้ำแม้ใช้บทอ่านต่างกัน ตรวจโครงสร้าง ป้องกันการเขียนทับพร้อมกัน และตรวจสคริปต์ตัวเกม รวมทั้งทดสอบการเลือกตัวละคร การปลดล็อก พลังคู่หู และการรับรางวัลด้วยชุดทดสอบภายใน

ทดสอบสร้างไฟล์เว็บและรวมไฟล์ฟังก์ชันแล้ว การเข้าสู่ระบบจริง อีเมลคำเชิญ และการบันทึกบนบริการ Netlify ต้องตรวจรับหลังเปิด Identity และติดตั้งในเว็บไซต์ของผู้รับงานตามขั้นตอนด้านบน
